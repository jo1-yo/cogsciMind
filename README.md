# Explaining Explanations of Cognition

An interactive educational website that explores the question:

**Are humans, bees, and AI doing the same thing when they navigate?**

This project introduces three major approaches to understanding cognition: symbolic systems, connectionist models, and embodied cognition. It compares how different agents — humans, bees, and AI — navigate the world and what that reveals about thinking.

## Project Information

**Title:** Explaining Explanations of Cognition  
**Website:** https://imjane.top/cogsciMind/  
**Author:** Yueqi Zhang  
**Institution:** Vassar College  
**Topic:** Cognitive Science, Navigation, and Cognition Across Agents

## Content Overview

The website follows the structure of the video lecture:

### Introduction | 0:00–0:45
Introduces the central question: whether different agents solve the same cognitive task in the same way.

### Part 1: Symbolic Systems | 0:45–2:00
Explains cognition as rule-based symbol manipulation, including GOFAI and the limits of purely logical models.

### Part 2: Connectionism | 2:00–3:00
Introduces pattern-based learning, neural networks, distributed processing, and modern AI systems.

### Part 3: Embodied and Extended Cognition | 3:00–4:15
Explores how cognition depends on the body, environment, and interaction with the world.

### Part 4: Philosophical Tensions | 4:15–5:15
Discusses functionalism, mechanism, consciousness, and the boundary between science and philosophy of mind.

### Closing Thoughts | 5:15–5:50
Reflects on different forms of cognition and what it means to think, navigate, and be alive.

## Features

- Main video lecture with chapter navigation
- Timestamped sections linked to written content
- Full transcript and expanded explanations
- Editable content cards in the browser
- Option to add new content sections
- Responsive design for desktop and mobile
- Clean layout with accessible typography
- Pure HTML, CSS, and JavaScript — no framework required
